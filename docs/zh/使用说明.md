# 使用说明

## 配置预设组

设置 → 插件 → 插件配置 → 找到 dsh-skill-injector 卡片：

1. 添加预设组，如组名 `grill`，技能每行一个：`grill-me`、`domain-modeling`
2. 保存（组名唯一、至少一个技能；缺失的技能会有 ⚠️ 提示，填充时自动跳过）

## 选择 / 反选

1. 回到对话，输入框左下角出现「预设」按钮
2. 点击 → 选择预设组（也可以一个都不选）
3. **再次点击当前选中的组 = 反选**，停止自动填充

## 自动填充

- 选中某组后，**空输入框**会在 ~500ms 内自动填入技能文本（一行、空格分隔，如 `/grill-me /domain-modeling `）
- 每条消息自动带技能；输入框**已有内容时不填充**，绝不打扰已有内容
- 选择状态全局持久化：刷新页面、重启 dsh、切换标签页都保持

## 已知边界

- 手动清空输入框后 ~500ms 内技能会被重新填入——这是设计行为（要发纯文本请先反选），不是 bug
- 技能缺失标记依赖当前会话；无会话时配置卡不显示 ⚠️，保存仍由后端校验
- 中文输入法组合期间、消息提交中不填充（守卫）
