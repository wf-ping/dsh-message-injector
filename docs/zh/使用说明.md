# 使用说明

## 配置预设组

设置 → 插件 → 插件配置 → 找到「消息注入」卡片（可折叠，点标题栏展开/收起）：

1. 点「+ 添加预设组」：新组插入**第一位**并自动展开（滚动到可见位置）
2. 填写组名（必填、唯一）、描述（可选）、内容（每行一条：技能调用带 `/` 如 `/grill-me`，或普通文本如 `请用中文回答`）
3. 组默认收起（只显示组名）；点击组名展开编辑；「启用」开关、上移/下移、删除在组头一行，收起时也可直接操作
4. 改完点「保存」（组名唯一、至少一行内容；`/` 开头的技能不存在时 ⚠️ 提示，注入时自动跳过）或「放弃」

> 快捷入口：对话输入框左下角「预设」菜单底部有「设置」项，一键打开设置面板并切到「插件」分区，配置卡自动展开并滚动到可见位置（定位失败时手动切一下分区，卡仍会自动展开）。

## 选择 / 反选

1. 回到对话，输入框左下角出现「预设」按钮
2. 点击 → 选择预设组（也可以一个都不选）
3. **再次点击当前选中的组 = 反选**，停止自动注入

## 自动注入

- 选中某组后，**空输入框**会在 ~500ms 内自动填入注入内容（一行、空格分隔，如 `/grill-me /domain-modeling `）
- **每条消息自动注入**；输入框**已有内容时不注入**，绝不打扰已有内容
- 选择状态全局持久化：刷新页面、重启 dsh、切换标签页都保持

## 使用建议

- **短小固定内容**（格式要求、固定前缀，如「请用中文回答」）→ 直接作为内容行，每条消息注入，简单直接
- **较长/复杂的指令或工作流** → 优先整理为 dsh **SKILL**，内容行只写 `/skill-name` 一行：
  - 内容可复用、可版本化，不必每条消息重复携带全文（省 token、省上下文）
  - 插件对 `/` 开头的行做**存在性校验**：技能缺失时配置卡 ⚠️ 警告、注入时跳过
  - 注意：技能是**会话级激活**——重复注入同一技能会造成技能全文重复进入上下文（浪费 token）。若只需首条消息携带，手动触发一次即可，或期待「仅首条注入」模式（畅想中）
- **多条内容混排**：普通文本与技能调用行可同组混排，注入时按序连接

## 典型使用流程

1. **配置**：设置 → 插件 → 插件配置 → 「+ 添加预设组」（新组插入**首位**并自动展开）→ 填组名/描述/内容（每行一条）→ 保存（或放弃）
2. **选择**：对话输入框左下角「预设」按钮 → 选中一个组（**再点一次当前组 = 反选**，停止注入）
3. **生效**：空输入框 ~500ms 自动注入内容到首行，可自由编辑后发送；发送后清空，**每条消息自动重复**
4. **维护**：组默认收起（只显示组名），点击展开编辑；启用/禁用、上移/下移、删除都在组头一行；选择器菜单底部「设置」可一键直达配置

## 已知边界

- 手动清空输入框后 ~500ms 内内容会被重新注入——这是设计行为（不需要请先反选），不是 bug
- 技能缺失标记依赖当前会话；无会话时配置卡不显示 ⚠️，注入时仍会跳过缺失的技能调用行
- 中文输入法组合期间、消息提交中不注入（守卫）
